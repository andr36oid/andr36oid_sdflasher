## andr36oid SD Flasher v0.4.0

Writing a card that already has several partitions now works on Windows.

- Fixed the "access denied" error on Windows when writing a card that already holds multiple partitions, such as an old Android install or an ArkOS or dArkOS card. The flasher now takes the whole disk offline for the write, so Windows can no longer keep one of the card's partitions mounted and block the write.
- Fixed the same permission error when copying hotfixes right after a fresh install, when the new Android partitions had just reappeared in Windows.

If a card reader does not allow taking the disk offline, the flasher falls back to the previous per-partition method, so single-partition cards are unaffected.
