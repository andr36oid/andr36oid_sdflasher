fixes from the 2026-10-24 release feedback. macs now see cards in the built-in SD reader, not just USB readers (apple silicon and intel). on windows, card listing no longer fails with "exit status 1" when one drive misbehaves, and it tells you the real reason if it still can't list. and if you launch the flasher from inside the downloaded zip without unpacking it, it now asks you to unpack it first, instead of failing later with a missing helper.
