## andr36oid SD Flasher v0.5.0

The flasher now has a full text-mode interface and starts on Windows machines that have no OpenGL driver at all.

- Added a complete headless text-mode flasher. It drives the same verified-write code as the window, with prompts instead of buttons, and needs no GPU, graphics driver or OpenGL. Start it with the -cli flag or A36_UI=cli. Every job the window offers is reachable with -action: flash (the default, including the in-place update and repartition that make this the patcher), hotfix (apply hotfixes to an existing card), kernel (check for and install a kernel update), restore (roll an interrupted update back from its recovery backup) and list (just show the drives).
- Text mode takes the same choices on the command line, so a whole flash can be scripted: -image or -download to pick the release, -drive to preselect the card, -profile to preselect the console, -mode install or update, -no-roms and -userdata to lay out install storage, -recovery for a restore, and -y to skip confirmations where it is safe. A non-removable disk always asks for its path to be typed, even with -y.
- Fixed the flasher failing to open any window on a clean Windows 11 install, in a virtual machine, or over Remote Desktop, where Windows ships only the Microsoft Basic Display Adapter and no OpenGL. The Windows zip now includes a software OpenGL renderer (Mesa llvmpipe, as opengl32.dll) beside the exe, so the window opens without a graphics driver. Rendering runs on the CPU, which is plenty for this screen. Delete the DLL if you would rather use your own GPU driver. If the window still cannot open, the flasher explains why in plain language and continues in text mode automatically.

This flasher pairs with the upcoming andr36oid GA image. It still requires an andr36oid release from 2026-10-22 or later.
