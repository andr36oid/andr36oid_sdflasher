## andr36oid SD Flasher v0.5.1

A maintenance release that fixes card detection on macOS.

- Fixed the flasher showing no cards on macOS. diskutil names the whole-disk flag "WholeDisk", but the flasher only read a "Whole" key that diskutil never sets, so every disk was skipped and no reader ever appeared. It now reads "WholeDisk" (and still honours the old "Whole" key), so inserted cards are listed again. Thanks to sayobaid for the fix.

Everything else is unchanged from v0.5.0: the full text-mode flasher, the verified-write patcher, hotfix and kernel-update actions, and the software-OpenGL Windows portable.

This flasher pairs with the andr36oid GA image. It still requires an andr36oid release from 2026-10-22 or later.
